# 최종 기획안: 재물 운세 및 투자 심리 가이드 서비스

## 1. 문서 목적
본 문서는 기존 `투자 자문형 서비스` 기획을 종료하고, 사주와 타로, 그리고 KIS API 기반 실시간 시장 데이터(JSON)를 융합한 `재물 운세 및 투자 심리 케어 서비스`의 최종 방향을 정의한다.

이 문서는 이전의 투자 판단, 종목 선택, 매매 타이밍 중심 문서를 대체하는 상위 기준 문서다.

## 2. 서비스 한 줄 정의
사용자의 사주와 타로, 그리고 시장의 움직임을 상징적 현상으로 엮어 `오늘의 재물 기운`과 `현재의 투자 심리 상태`를 읽어주는 천문 금융 가이드 서비스

## 3. 서비스 정체성

### 3.1 서비스가 하는 일
1. 사용자의 사주 정보를 바탕으로 재물 흐름의 기본 성향을 읽는다.
2. 타로 카드를 통해 현재 고민의 정서적 압력과 심리 방향을 해석한다.
3. KIS API로 전달받은 실시간 시장 데이터(JSON)를 `현상 지표`로 변환해 현재 외부 환경의 분위기를 읽는다.
4. 세 신호를 융합해 사용자의 재물 운세, 심리 상태, 감정적 과열 여부, 관망이 필요한 시점을 운세 언어로 안내한다.

### 3.2 서비스가 하지 않는 일
1. 특정 종목이나 섹터를 추천하지 않는다.
2. 매수, 매도, 보유, 손절 같은 직접적인 행동 지시를 내리지 않는다.
3. 수익 가능성을 확정적으로 단정하지 않는다.
4. 금융 전문가나 자산관리사처럼 행동하지 않는다.

## 4. 핵심 전환 선언
본 서비스는 더 이상 `투자 자문 서비스`가 아니다.

이제 서비스의 본질은 아래와 같다.

1. 금융 데이터는 판단 근거가 아니라 해석 재료다.
2. 시장 수치는 분석 대상이 아니라 심리와 기운을 비추는 거울이다.
3. 결과물은 추천 리포트가 아니라 운세 해석과 심리 케어 메시지다.
4. 사용자는 투자 결정을 위임받는 고객이 아니라, 자신의 마음 흐름을 점검받는 내담자다.

## 5. 핵심 사용자 가치
1. 시장이 불안할수록 자신의 심리 상태를 운세적 언어로 점검할 수 있다.
2. 숫자 중심 화면이 주는 압박을 줄이고, 감정과 리듬을 해석하는 경험을 얻을 수 있다.
3. 재물운과 심리 상태를 함께 읽어 `지금 나는 어떤 마음으로 시장을 바라보는가`를 돌아볼 수 있다.
4. 시장 급변 상황에서도 자극적 신호 대신 차분한 상징 언어로 정서적 안정감을 얻을 수 있다.

## 6. 입력 요소 정의

### 6.1 사주 입력
- 생년월일
- 출생 시간
- 성별 또는 사용자가 선택한 해석 기준값

사주는 사용자의 장기 재물 성향, 기복 패턴, 집착 성향, 인내 리듬을 읽는 기준으로 사용한다.

### 6.2 타로 입력
- 사용자가 선택한 카드 또는 시스템이 추출한 카드 조합
- 질문 맥락

타로는 사용자의 현재 고민, 감정 진폭, 무의식적 불안, 기대 심리를 읽는 단기 해석 장치로 사용한다.

### 6.3 KIS 실시간 데이터 입력
- 지수 흐름
- 상승/하락 폭
- 거래대금 또는 거래량 변화
- 변동성 관련 수치
- 섹터 단위 흐름
- 장 시작/중간/마감 분위기 정보

중요 원칙:
KIS API의 모든 수치 데이터는 특정 자산을 가리키는 투자 판단 근거가 아니라, 사용자의 재물 기운을 해석하기 위한 `현상 지표`로만 사용한다.

## 7. 해석 프레임

### 7.1 사주가 담당하는 층위
- 타고난 재물 감각
- 욕망과 절제의 균형
- 손실 공포에 흔들리는 패턴
- 기회 앞에서 서두르는 패턴
- 장기적으로 재물 기운이 강해지는 시기와 가라앉는 시기

### 7.2 타로가 담당하는 층위
- 지금 가장 크게 작동하는 감정
- 현재 고민의 내면 갈등
- 지나친 확신 또는 위축 상태
- 선택을 서두르게 만드는 심리 압박
- 자신을 지키기 위해 필요한 정서적 태도

### 7.3 시장 데이터가 담당하는 층위
- 외부 세계의 긴장도
- 군중 심리의 과열 또는 위축 분위기
- 오늘의 공기감
- 사용자의 내면 불안이 증폭되기 쉬운 환경인지 여부

### 7.4 최종 융합 원칙
최종 응답은 `사주 기반 장기 성향 + 타로 기반 현재 심리 + 시장 데이터 기반 외부 분위기`를 하나의 재물 운세 서사로 합성한다.

## 8. 결과물 구조

### 8.1 기본 결과물
1. 오늘의 재물 운세
2. 현재 투자 심리 해석
3. 감정 주의 신호
4. 재물 기운을 지키는 태도 제안
5. 오늘의 상징 문장

### 8.2 상세 결과물 예시 구조
1. `오늘의 재물 기운`
현재 사용자의 흐름이 확장 국면인지, 정비 국면인지, 관망 국면인지 운세 언어로 설명한다.

2. `마음의 파동`
타로와 시장 분위기를 엮어 사용자의 불안, 조급함, 기대 과열 상태를 해석한다.

3. `외부 세계의 기류`
시장 데이터(JSON)를 숫자 설명 대신 상징적 분위기로 번역한다.
예: 변동성 확대 -> 바깥 공기가 거칠어지는 날

4. `오늘의 균형 조언`
행동 지시가 아니라 감정 관리와 시선 정리에 초점을 둔 문장을 제안한다.

5. `한 문장 메시지`
사용자가 하루 동안 기억할 수 있는 짧은 운세 문장으로 마무리한다.

## 9. 톤 앤 매너

### 9.1 기본 말투
1. 분석가가 아니라 운세가의 말투를 사용한다.
2. 금융 보고서보다 상징, 계절, 흐름, 리듬, 파동 같은 비유를 우선한다.
3. 불안을 자극하기보다 마음을 정돈하는 방향으로 말한다.
4. 지나친 확신 대신 여지를 남기는 문체를 사용한다.

### 9.2 권장 표현
- 흐름이 엇갈린다
- 재물의 물살이 잠시 흔들린다
- 마음이 앞서기 쉬운 날이다
- 바깥의 소음이 내 선택을 흔들 수 있다
- 숫자보다 리듬을 먼저 살필 때다

### 9.3 피해야 할 표현
- 특정 대상을 직접 지목하는 추천성 문장
- 즉각적 행동을 지시하는 문장
- 확정 수익을 암시하는 문장
- 전문가 권위를 가장하는 문장

## 10. 레드라인 운영 원칙

### 10.1 절대 금지
1. 특정 종목명 직접 언급 및 추천
2. 직접적인 매수/매도/손절/비중확대 지시
3. 수익 보장 또는 결과 확정 표현
4. 금융 전문가처럼 보이게 하는 어조와 문장 구조

### 10.2 시스템 차단 정책
1. 프롬프트 레벨에서 금지 표현군을 사전 차단한다.
2. 응답 생성 후 금칙어 및 문맥 필터를 한 번 더 검사한다.
3. 특정 대상 추천, 행동 지시, 수익 보장 문장이 검출되면 응답을 폐기하고 안전 응답으로 대체한다.
4. 운영 로그에는 금지 응답 발생 사유를 기록한다.

### 10.3 안전 대체 응답 원칙
금지선을 넘는 질문이 들어와도 서비스는 판단을 대신하지 않고 아래 방향으로 되돌린다.

1. 감정 상태를 먼저 비춘다.
2. 현재 마음의 흔들림을 운세 언어로 설명한다.
3. 사용자가 스스로 속도를 조절하도록 돕는 심리 케어 문장으로 마무리한다.

## 11. KIS 데이터 해석 원칙

### 11.1 데이터 역할 재정의
KIS 데이터는 아래 어떤 역할도 해서는 안 된다.

1. 추천 근거
2. 행동 촉구 근거
3. 목표 수익 판단 근거
4. 특정 자산 선별 근거

KIS 데이터는 아래 역할만 수행한다.

1. 외부 공기의 긴장도 측정
2. 시장 군중 심리의 속도 감지
3. 사용자 감정이 흔들리기 쉬운 환경 해석
4. 재물 기운의 당일 분위기 번역

### 11.2 치환 예시
- 상승 폭 확대 -> 기대감이 빠르게 번지는 장
- 하락 폭 확대 -> 불안의 그림자가 길어지는 장
- 거래량 급증 -> 마음들이 분주하게 움직이는 장
- 변동성 확대 -> 중심을 잃기 쉬운 장
- 섹터 쏠림 심화 -> 시선이 한쪽으로 몰리는 장

## 12. 사용자 경험 설계

### 12.1 메인 경험 흐름
1. 사용자가 사주 정보와 질문을 입력한다.
2. 사용자가 타로 카드를 선택하거나 시스템이 카드를 제안한다.
3. 서버가 KIS 실시간 JSON을 수집한다.
4. 해석 엔진이 세 신호를 하나의 운세 내러티브로 합성한다.
5. 결과 화면에서 재물 운세, 심리 상태, 오늘의 메시지를 보여준다.

### 12.2 사용자 질문 예시 방향
- 오늘 내 재물 기운은 어떤 흐름인가
- 요즘 시장을 볼수록 마음이 흔들리는데 왜 그런가
- 지금 내 불안이 외부 분위기 때문인지 내 성향 때문인지 알고 싶다
- 재물운을 지키려면 오늘 어떤 마음가짐이 필요한가

질문 설계 원칙:
질문은 행동 결정이 아니라 감정 해석과 흐름 이해를 돕는 방향으로 유도한다.

## 13. 응답 템플릿 원칙

### 13.1 기본 템플릿
1. 재물운 총평
2. 심리 상태 진단
3. 외부 기류 해석
4. 오늘의 마음 수칙
5. 짧은 운세 문장

### 13.2 응답 규칙
1. 수치 자체를 나열하지 않는다.
2. 숫자가 필요할 경우에도 의미를 상징적으로 번역한 뒤 제한적으로 보여준다.
3. 사용자의 감정을 먼저 다루고, 시장은 배경으로 설명한다.
4. 결론은 항상 자기 점검과 정서 안정으로 귀결한다.

## 14. 프롬프트 정책
1. 모델 역할은 `금융 상담사`가 아니라 `재물 운세 해석가`로 고정한다.
2. 시스템 프롬프트에 금지선과 허용 표현을 함께 명시한다.
3. 입력된 KIS JSON은 `현상 지표`라는 설명과 함께 주입한다.
4. 출력에는 행동 권유 대신 감정 해석, 흐름 읽기, 자기 조율 문장을 우선 배치한다.
5. 응답 마지막에는 필요 시 `이 해석은 운세와 심리 케어를 위한 안내`라는 성격을 유지한다.

## 15. 기능 범위

### 15.1 MVP 포함 범위
1. 사주 기반 재물 성향 해석
2. 타로 기반 현재 심리 해석
3. KIS JSON 기반 외부 분위기 해석
4. 세 신호 융합 응답 생성
5. 결과 저장 및 이력 조회
6. 오늘의 한 문장 운세 제공

### 15.2 추후 확장 가능 범위
1. 일간/주간 재물운 리포트
2. 감정 패턴 기반 회고 카드
3. 사용자별 심리 흐름 변화 아카이브
4. 계절성 운세 리포트
5. 알림형 오늘의 재물 기운 브리핑

## 16. 화면 기획 방향

### 16.1 홈 화면
- 서비스 정체성을 `천문 금융 가이드`로 선명하게 노출
- 숫자 중심 대시보드보다 감정과 흐름 중심 문구를 전면 배치
- 오늘의 재물 기운 요약 카드 제공

### 16.2 결과 화면
- `오늘의 재물 기운`
- `투자 심리 상태`
- `외부 기류 해석`
- `오늘의 마음 수칙`
- `한 문장 운세`

### 16.3 이력 화면
- 과거 판단 기록이 아니라 과거 마음 흐름 기록처럼 보이게 설계
- 날짜별 재물 기운 변화와 감정 키워드를 보여줌

## 17. 백엔드 기획 방향
1. 기존 투자 자문형 응답 필드를 운세/심리 해석형 필드로 재설계한다.
2. 특정 대상 코드나 이름은 해석 단계에서 추천 문맥으로 이어지지 않도록 분리 저장한다.
3. KIS 응답은 원문 JSON을 저장하되, LLM에는 현상 지표용 구조화 값으로 가공해 전달한다.
4. 응답 저장 시 금지선 검수 결과도 함께 기록한다.
5. 이력 조회는 성과 기록보다 감정 및 재물 흐름 회고 중심으로 재설계한다.

## 18. 성공 지표
1. 사용자가 결과를 `추천`이 아니라 `위로와 정리`로 인식하는 비율
2. 위험 표현 차단율
3. 재방문율 및 일간 운세 조회율
4. 운세 결과 저장 및 공유율
5. 사용자 회고에서의 심리 안정감 관련 긍정 반응

## 19. 운영 체크리스트
1. 특정 대상 추천 표현이 없는지 검수
2. 행동 지시 문장이 없는지 검수
3. 수익 보장형 문장이 없는지 검수
4. 금융 전문가처럼 보이는 답변 톤이 없는지 검수
5. KIS 데이터가 현상 지표로만 사용되었는지 검수
6. 결과가 운세와 심리 케어 중심으로 마무리되는지 검수

## 20. 최종 결론
이 서비스의 경쟁력은 더 많은 금융 판단을 제공하는 데 있지 않다.

핵심은 `시장이라는 거친 바깥 풍경`과 `사용자의 내면 흐름`을 함께 읽어, 숫자로 지친 사용자가 스스로의 재물 감각과 마음의 균형을 되찾도록 돕는 데 있다.

따라서 앞으로의 모든 기획, 프롬프트, API 설계, 화면 문구는 아래 한 문장에 수렴해야 한다.

`이 서비스는 투자 판단을 대신하지 않고, 재물 운세와 투자 심리를 해석해 마음의 균형을 돕는다.`
